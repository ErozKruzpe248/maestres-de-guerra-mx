# Maestres de Guerra México

Sitio web oficial de la comunidad Maestres de Guerra México.

## Contenido

- Sitio estático en `dist/`
- Publicación automática mediante GitHub Pages
- Sin dependencias ni proceso de compilación

## Publicación

La acción de GitHub incluida publica el contenido de `dist/` al enviar cambios a la rama `main`.

El dominio personalizado se configurará después de confirmar el nombre exacto adquirido en Akky.
